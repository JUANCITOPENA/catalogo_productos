# 🛍️ Catálogo Oficial de Productos - Super Goods SRL

Portafolio digital de productos en Alta Definición (Ultra HD), sincronizado con GitHub RAW y preparado para integración con sistemas ERP, POS, Excel e Inteligencia Artificial.

🌐 **Sitio Web en Vivo (GitHub Pages):**  
👉 **[https://juancitopena.github.io/catalogo_productos/](https://juancitopena.github.io/catalogo_productos/)**

---

## 📁 Estructura del Repositorio

- **index.html**: Aplicación web SPA completa con:
  - 🛍️ **Showroom Interactivo**: 51 productos categorizados (Bebidas, Alimentos, Cuidado del Hogar, Cuidado Personal).
  - 🔄 **Selector de Fondos**: Alternar entre fotos con fondo original de imprenta y fotos PNG transparentes sin fondo.
  - 📊 **Base de Datos & Enlaces GitHub RAW**: URLs directas con estado HTTP 200 garantizado.
  - 📑 **Extractor PDF**: Herramienta integrada para cargar nuevos catálogos y extraer productos automáticamente.
  - 📥 **Exportación**: Descarga en Excel (.xlsx) con hipervínculos activos, CSV, JSON y paquete ZIP.
- **catalogo_productos_Sin_Fondos/**: 51 imágenes en formato PNG con fondo transparente ultra limpio.
- **imagenes_ultra_hd_Con_Fondos/**: 51 imágenes en alta resolución con fondo original.
- **Catalogo_Productos.xlsx**: Archivo Excel maestro con fórmulas, formato corporativo y links directos a cada foto.
- **Catalogo_Productos.csv**: Archivo de texto delimitado por punto y coma (UTF-8 con BOM).
- **Catalogo_Productos.json**: Estructura de datos completa en JSON.
